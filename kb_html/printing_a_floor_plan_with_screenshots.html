Plan Location Choices

Floor plans can be accessed from two different CSI options within the Space Management Module: Sites (or Floor Plans) or Views. See General Navigation for more details.

Sites (or Floor Plans) – Opening a floor plan from Sites (left navigation bar) or Floor Plans (from home page), includes both Exporting PDF and Print options in the Actions dropdown menu.

View – Opening a floor plan while interacting with a view will only provide the Print option from the Actions dropdown menu.

How to Print or Export

It is possible to print or export to PDFs and both options are available with any Graphic View.

The differences are based on how CSI interacts with Adobe PDF printer options. Because printing and exporting vary with a user’s browser, printer and Adobe settings, the user may see some variation from the training materials.

To Print or Export

Printing features in CSI include:

  • Quick and easy for the selected single floor
  • Can print a zoomed area or full floor
  • Can use any printer (including copier, fax, Windows writer, PDF, etc) available on a user’s computer
  • Being an available option for floor plans opened from both Sites (or Floor Plans) or Views

Exporting features in CSI include:

  • Creating PDF formatted documents
  • Provides options to include a name, header, footer, and date
  • Can print multiple floors in a single export
  • Being an available option only for plans opened through the Sites (or Floor Plans) links
Printing a Plan

Using the Print function is a convenient way to generate a single floor plan from any printer available on the user’s computer.

  • Start by selecting the floor plan and graphic view desired
  • Use the dropdown menu in the Actions button to select Print (or Shift + P)

  • Select the     button for the floor plan area to print
    • The current viewable area button can be used to zoom in and capture a specific area of the floor plan.
    • The entire floor plan button is used   to print the whole floor, including the titleblock across the bottom with the building name, number, floor, and date it was last uploaded to CSI.

  • The printer menu pops up with several options
    • Printer – Choose the appropriate printer from the available options in the drop-down list.
    • Pages – All or 1 are both appropriate for a single floor plan
    • Layout – Landscape will typically work best
    • More settings – Expands to show other printer options available to the user’s computer
    • Headers and footers – Adds the print date, file name and page number

  

Exporting a Plan(s)

Exporting floor plans as PDFs offers customizable layout options and the ability to export multiple plans simultaneously. Note: Export functions are only available when floor plans are accessed through links in Sites or Floor Plan Graphic Views.

  • Start by selecting the graphic view desired shown above.
    • Floor plan selection can happen here or during the export
  • Use the dropdown menu in the Actions button to select Export as PDF (or Shift + E)
  • The Export as PDF menu includes several export details.
    • *Name – This is a required field where the user can enter a name
    • Document header – A custom header can be created here
    • Document footer – A custom footer can be created here
    • Include Default Header – Automatically adds facility and floor details
    • Pagination – Automatically add page numbers
    • Date and Time – Adds the date and time the export was created
    • Graphic View – The selected Graphic View will be displayed here. It needs to be selected from the floor plan page and cannot be changed here
    • *Floors – This is another required field.
      • The current floor will be included automatically
      • Use the Select Floors button to include additional floors from a navigation tree with facility number (name) and floor number.
        • The entire facility can be selected by checking the box at the facility level
        • Individual floors can be selected or deselected by expanding the facility and checking or unchecking the desired floors.
        • Use the up and down arrows on the right of the listed floor plans if a particular order is desired in the final PDF
        • NOTE: The more floors selected, the bigger the file, the longer it will take to complete.
  • Separate files by – The user can decide how many PDF files should be created.
    • None – All selected floors will be in a single file
    • Site – All selected floors from the same Site (Main, Proximate, or Outlying) will be in separate files
    • Building – Selected floors with each building will be exported into a file for the building
    • Floor – This allows the user to create a separate file for each floor
  • Page size – Select desired paper size and orientation
    • Only paper sizes available on a user’s computer will be on the dropdown list
    • Landscape is the recommended orientation for plans
  • Margin size – The options are small, medium, and large. Individual printer details may vary
  • Font size – This field only adjusts the font size for the title, headers, footers, and page numbers. It does not change the size of the text within the floor plan

 

  • Exporting the document with the selections shown above will provide the following results.
    • *Name – Names the PDF file
    • Document header – User text is in upper left corner
    • Document footer – User text in in lower left corner
    • Default header – Lists Site. Facility #, Floor, Graphic View in upper left corner (Main, 0020 01, SMO Plan Print in this example)
    • Pagination – Shows Page # of Total pages (Page 1 of 1 in this example)
    • Date and time – The time stamp is located in the bottom center of the page

Helpful Tips

Printing and exporting can vary by every user, printer, and Adobe preference. There are a few things that may optimize the final exported plan.

  • If the text is blurry or pixilated :
    • Try increasing the resolution in that printer’s setting
  • If there is extra white space around the plan :
    • Try selecting the floor directly from the Select Floors button on the Export option
    • Try maximizing the floor plan on the web page using the zoom window in CSI and/or minimizing the web browser, then scaling it to best fit the floor before using the Print option to print current viewable area
  • Additional tips will be posted as additional issues arise.
User Responsibilities

Reports are exported with a report name, date, and disclaimer information. For more details, see the Access to CSI lesson.

Be especially mindful of storing and sharing floor plans of very sensitive facilities as defined in policy UW-6060 Distribution of Facility Data, Documents, and Graphics Information. Examples of these facilities include:

  • Animal holding – vivarium and barns
  • Public gathering – stadiums and arenas
  • Housing – dorms and apartments
