The Campus Space Information (CSI) Landing Page is the first screen users see upon logging in. It provides quick access to essential features, including account information, floor plan graphics, data views, and reports.

Back to CSI Lesson List

Landing Page – Key Areas

Top Navigation Menu
  • Facilities Planning & Management Logo – Click on this icon to return to the landing page.
  • Silhouette Icon – This area displays your predefined user role, which determines your access in CSI. Most other information under the silhouette icon is not relevant to general users.
  • Settings Icon – Users can update display settings; however, it is recommended to keep the default settings.
  • Click Hide Navigation to collapse the left sidebar. Click Show Navigation to bring it back.
  • Select User Preferences to adjust your navigation layout and other personal settings.
  • Most other options in the settings menu are not typically useful for general users.
  • Global Search Bar – Users will be able to search the entire CSI site for information using the global search bar.
Left Navigation Menu (Sidebar Icons)
  • Home Icon – Returns users to the landing page.
  • Star Icon – Allows users to save favorite views.
  • Floor Plan Icon (Space Management module) – Users can view facility information, space data, floor plans and reports.
  • Building Icon (Higher Education Survey module) – This module is currently inactive. More information will be provided when the module is activated.
Homepage (Center of the Page)
  • Floor Plan Graphic Views – Interact with floor plans, including basic, color-coded, and annotated plans for main campus facilities, proximate facilities, and outlying facilities.
  • Views – Explore detailed data for facilities, floors and rooms in a clickable interface.
  • Reports – Access and explore facility, floor and room data in tabular format.
  • Need Help? – Find links to training resources or contact support.
