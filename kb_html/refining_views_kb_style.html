Search Bars

Throughout all pages of CSI, you will notice multiple search bars, often on the same screen. It is important to know the difference between them to ensure you are using the correct one for each situation.

Global Search

The red outline below is the global search for the entire CSI site.

  • Type your desired content in this box.
  • Click the search icon.
  • Results may be found in a field not shown in the displayed results.
  • Results will display for the following information:
    • Rooms
    • Employees
    • Others TBD

View Search

The yellow outline below is the search for any specific View.

  • Type your desired content in this box.
  • Click the search icon.
  • Results are limited to the view on the screen.
  • Results may be found in a field not shown in the displayed results.

Filters

Filters allow you to narrow information further than the search bar by setting criteria on multiple different fields.

Applying Filters

Use the following steps to apply filters:

  1. Click the Filter icon in the upper right of the view, outlined in red below. This opens filter options for each field in the view.
  2. Enter text in the text box for the field you want to filter.
  3. Click the filter icon next to the field being filtered.
  4. Select the desired filter action from the dropdown options.
  5. Results will be displayed.
  6. Multiple fields may be filtered.
    • Finish filtering one field before moving to the next.
    • There is no limit to the number of filters that can be applied.

Removing Filters

Remove an individual filter
  • Click the filter icon next to the desired field.
  • Select “NoFilter” from the dropdown list.
  • This filter is removed.
  • Repeat for each field where a filter has been applied.
Remove all filters
  • Click refresh on the web browser.
  • The exact icon appearance and location will vary with the browser being used.
Result Page Size

You can adjust the number of results displayed on a page as shown below.

  • Default size – 20 rows of results is the default.
  • Adjust size – Use the dropdown to select the desired number of rows.
  • Limitation – Increasing the page size may increase loading time.

Saved Queries

Saved queries are available on some views to provide easy access to common filtering.

Click the arrow shown below to get the dropdown options for saved queries.

  • The list options are unique to the view.
  • The options are preset for the single field shown.
  • Additional filters can be applied to further limit results following the steps above.
  • To remove saved query filtering, select “Show All”.
    • Any additional filters will remain.
  • To remove all queries and filters, use the web page refresh button.
